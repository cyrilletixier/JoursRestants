API Restants

Envoyez une date de naissance et un sexe, recevez un nombre de jours. L'upload de votre âme n'est pas encore supporté.

Mode URL (navigateur)

Dans un navigateur, la page se réduit au JSON quand on lui passe les paramètres :

api.html?date=1985-06-15&sexe=H

Réponse : un objet naissance, sexe, jours_restants (à 50 %), date_deces_probable, esperance_vie_restante_ans. En cas d'entrée invalide, un champ erreur poliment bordélique.

Mode bibliothèque (machines)

GitHub Pages ne calcule rien côté serveur : l'API, c'est le JavaScript. Incluez les deux scripts et appelez la fonction, le calcul est local et instantané.

<script src="https://cyrilletixier.github.io/JoursRestants/life.js"></script>
<script src="https://cyrilletixier.github.io/JoursRestants/api.js"></script>
<script>
  const r = JoursRestantsApi.compute("1985-06-15", "H");
  console.log(r.jours_restants);
</script>

En Node.js, même combat :

const fs = require("fs");
eval(fs.readFileSync("life.js", "utf8"));
eval(fs.readFileSync("api.js", "utf8"));
const r = JoursRestantsApi.compute("1985-06-15", "H");
console.log(r);

API statique : aucun serveur, aucune base de données, aucun log. Vos dates de naissance ne quittent jamais le navigateur, c'est l'avantage du calcul local : personne d'autre ne sait quand vous partez, pas même nous. Le champ jours_restants est la médiane de survie aux tables INSEE 2025 provisoires (population moyenne du sexe), soit 50 % de chances d'être encore là. Pour affiner avec tabac, alcool, sport et niveau de vie, la page Jours Restants s'occupe de votre ego, l'API s'occupe de la statistique brute.

Source : INSEE — Quotients de mortalité par sexe et âge
